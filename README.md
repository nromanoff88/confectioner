# 🎂 CRM Кондитера • Бот и Mini-App для мессенджера MAX

Полноценный сервис для кондитерской в мессенджере **MAX (`platform-api2.max.ru`)** с раздельными чатами клиентов, карточками предпочтений/адресов, ведением активного заказа, историей заказов и S3-хранилищем фотографий тортов.

---

## Возможности

1. **Отдельные диалоги без хаоса (Mini-App панель оператора)**:
   * Все клиенты, написавшие боту в MAX, отображаются в аккуратном списке диалогов со счётчиками непрочитанных сообщений и статусами активного заказа.
   * Вы отвечаете клиенту прямо из интерфейса (текстом или с фотографией) — клиент получает ответ в своём диалоге от имени бота.
   * Новые сообщения и фотографии от клиентов приходят в интерфейс мгновенно в реальном времени (Server-Sent Events).
2. **Карточка клиента**:
   * Имя, телефон (автоматически заполняется, когда клиент нажимает кнопку `📱 Поделиться телефоном` в боте, или редактируется вручную).
   * Адрес доставки по умолчанию.
   * Описание клиента: вкусовые предпочтения, аллергии, скидки, заметки.
3. **Активный заказ**:
   * Поля: что хочет клиент (`cake_description`), начинка/вкус, декор и надпись на торте, вес продукта (кг), дата и время готовности, способ получения (доставка / самовывоз), адрес, общая стоимость, предоплата и статус оплаты.
   * Галерея **Референсов от клиента** и **Фото готового торта** с хранением в S3 (MinIO).
   * На любой фотографии в чате есть быстрые кнопки `📌 В референс заказа` и `🎂 В фото готового торта`, которые в один клик прикрепляют фото из переписки к заказу.
   * **Автоматические уведомления клиента**: при переключении статуса заказа (`Новый` → `Ожидает предоплаты` → `В работе` → `Готов к выдаче` → `Выполнен`) бот автоматически отправляет клиенту в MAX сообщение с деталями заказа.
4. **История заказов с фотографиями тортов**:
   * Когда статус заказа меняется на `Выполнен` (или `Отменён`), заказ автоматически переносится в **Историю заказов** этого клиента вместе со всеми фотографиями тортов, весом, начинкой и ценой.

## Быстрый старт (Docker Compose)

1. При необходимости отредактируйте файл `.env`:
   ```env
   MAX_BOT_TOKEN=ваш_токен_из_business_max_ru
   MAX_BOT_NAME=имя_вашего_бота
   OPERATOR_IDS=ваш_user_id_в_max
   DEV_MODE=true
   ```
   *(Если оставить `MAX_BOT_TOKEN` пустым при `DEV_MODE=true`, сервис запустится в локальном демо-режиме с тестовыми клиентами, перепиской и примерами заказов с фотографиями тортов в S3).*

2. Запустите все контейнеры:
   ```bash
   docker compose up --build -d
   ```

3. Откройте панель оператора в браузере:
   * **Интерфейс Mini-App / CRM**: [http://localhost:3000](http://localhost:3000)
   * **Backend API Healthcheck**: [http://localhost:8080/api/health](http://localhost:8080/api/health)
   * **MinIO S3 Console**: [http://localhost:9001](http://localhost:9001) (логин: `minioadmin`, пароль: `minioadmin_secret`)

## Подключение к MAX (business.max.ru)

1. Перейдите в [business.max.ru](https://business.max.ru) → **Чат-боты** → выберите вашего бота → **Настройки**.
2. Скопируйте токен и укажите его в `.env` в переменной `MAX_BOT_TOKEN`.
3. Для открытия Mini-App внутри приложения MAX на телефоне пробросьте HTTPS-туннель на порт `3000` (например, через `cloudflared tunnel --url http://localhost:3000` или `ngrok http 3000`) и укажите полученный HTTPS-адрес в настройках Mini-App вашего бота.
4. Перезапустите бэкенд:
   ```bash
   docker compose up -d --build backend
   ```
