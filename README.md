# 🎂 Учёт клиентов и заказов кондитера — бот и Mini-App для MAX

Бот — это личная система учёта кондитера. Клиенты общаются с кондитером напрямую в обычных чатах MAX,
а бот и Mini-App («админка») нужны, чтобы записывать клиентов, вести заказы и ничего не забывать.

## Возможности

- **Клиенты**: имя, телефон, адрес, описание (аллергии, предпочтения), теги (VIP, аллергик, корпоратив, свои),
  поиск и фильтр по тегам, журнал заметок («созвонились, согласовали начинку»).
- **Заказы**: что хочет клиент, начинка, декор/надпись, вес, дата и время, доставка/самовывоз, цена, предоплата,
  статус оплаты, статусы выполнения, фото-референсы и фото готового торта (S3).
  Выполненные и отменённые заказы уходят в историю клиента с фотографиями тортов.
- **Календарь**: заказы по датам (просрочено / сегодня / завтра / дальше / без даты).
- **Напоминания в боте**: «⏰ завтра в 12:00 доставка торта Анне» — за 1 час … 2 дня до срока (настраивается в заказе).
- **Статистика**: выручка за месяц, число и вес тортов, средний чек, новые клиенты, к доплате, топ клиентов.
- **Несколько кондитеров**: у каждой кондитерской своё изолированное пространство. В одно пространство можно
  пригласить помощников — они видят общую базу. Приглашение: кнопка «Пригласить кондитера» в боте
  или вкладка «Команда» в админке (ссылка `https://max.ru/<бот>?start=join_<код>` или `/join <код>`).

## Как работает бот

Бот отвечает только кондитерам (личный диалог). По `/start` показывает меню:
**Открыть админку**, **Новый клиент**, **Новый заказ**, **Сегодня**, **Завтра**, **Статистика месяца**, **Пригласить**.
Сообщения клиентов бот не принимает.

## Запуск (Docker Compose)

1. Скопируйте `.env.example` в `.env`, заполните `MAX_BOT_TOKEN`, `MAX_BOT_NAME`, пароли БД и S3.
2. Запуск локально:
   ```bash
   docker compose up --build -d
   ```
   Админка: http://localhost:3000 — открывается **только внутри MAX**. Для отладки в браузере поставьте
   `DEV_MODE=true` и откройте `http://localhost:3000/?dev_user=1` (на сервере DEV_MODE должен быть `false`).
3. Продакшен с HTTPS (Caddy + Let's Encrypt):
   ```bash
   docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
   ```
4. В [business.max.ru](https://business.max.ru) → Чат-боты → ваш бот → Настройки укажите URL мини-приложения
   (`https://<ваш-домен>`).

## Доступ и безопасность

- Каждый запрос админки проверяется по подписи `initData` MAX (HMAC-SHA256 по токену бота).
  Данные ограничены пространством кондитера — чужие клиенты и заказы недоступны.
- `REGISTRATION_OPEN=false` закрывает самостоятельную регистрацию (вход только по приглашению или из `OPERATOR_IDS`).
- Данные старой версии (чат-бот) сохраняются в таблицах `legacy_*` и в новом интерфейсе не используются.
